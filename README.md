# weread-to-flomo

把微信读书的划线和想法，批量导入 flomo。

微信读书 App 里攒的划线、批注、问答笔记，通过微信读书官方 Skill 网关拉取，按规则自动分成三类（划线 / 问答 / 批注），贴好 `#微信读书/书名` 标签写进 flomo。写作时按标签一搜，整本书的笔记全部调出来。

## 安装

在支持 skills 的 AI 工具（WorkBuddy 等）里发送：

```
npx skills add mayigululu-hash/weread-to-flomo
```

## 前提

1. **微信读书 Skill**：已安装微信读书官方 Skill 并配好 API Key（微信读书 App 内「微信读书 skill」入口复制指令，或 `npx skills add Tencent/WeChatReading`）
2. **flomo 连接**：flomo 设置里开启「MCP / AI 工具连接」，复制接入 token 配置到你的 AI 工具（详见 flomo 官方文档）

## 使用

对 AI 工具说一句话：

```
把《洞见写作》的微信读书笔记导入 flomo
```

它会：拉取笔记 → 自动分类（划线 / 问答 / 批注）→ 去重 → 给你看一份整书预览 → 你确认后写入 flomo → 汇报结果。

## 设计说明

- 分类规则是确定性的（前缀判断），移植自 Anki 社区插件「微信读书 - 学习骇客」的分类逻辑，无前缀的想法保留为批注
- 写入前整书预览、用户确认后才批量写入；部分失败如实汇报
- 手动触发，一次一本书，不设后台自动化
